# Security Policy

## Supported Versions
Only the latest released version of the Karmatix .NET Academy platform and samples is supported with security updates.

| Target | Supported |
| --- | --- |
| Karmatix .NET Academy Platform | Yes |
| /samples (Targeting .NET 10 LTS) | Yes |

## Reporting a Vulnerability
If you discover a potential security vulnerability within this repository, website, or sample projects, please report it privately:

- **Email**: hello@karmatix.in (or contact form at https://karmatix.in/contact)
- **Subject**: `[SECURITY] Karmatix .NET Academy Vulnerability Report`

Please include:
1. Detailed description of the issue.
2. Steps to reproduce or proof-of-concept.
3. Impact assessment.

We take security seriously and will acknowledge your report within 48 hours and coordinate remediation before public disclosure.
