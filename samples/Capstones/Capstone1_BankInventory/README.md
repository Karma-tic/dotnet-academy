# Capstone 1: Bank & Inventory Console App

## Overview
A production-quality console application demonstrating core Object-Oriented Programming (OOP) concepts, encapsulation, custom domain validations, collection management, and transaction logging in C# 14 and .NET 10 LTS.

## Key Concepts
- Immutable records for transaction history
- Encapsulated business state (safe private setters, exception-driven domain invariants)
- Generic dictionaries and collection expressions
- Unit testing ready

## Running Locally
```bash
dotnet run --project samples/Capstones/Capstone1_BankInventory
```
