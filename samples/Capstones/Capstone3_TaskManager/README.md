# Capstone 3: Task Manager Web Application

## Overview
Demonstrates state machines, task assignment, identity-based authorization checks, priority levels, and unit-testable service business logic.

## Key Features
- Enumerations for Priority and Workflow Status
- Domain state transitions (\`MarkCompleted()\` with timestamp capture)
- User isolation safeguards
- Ready for Razor Pages, Blazor Web Apps, or API backends

## Running Locally
```bash
dotnet run --project samples/Capstones/Capstone3_TaskManager
```
